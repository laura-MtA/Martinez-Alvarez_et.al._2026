# Figure 2 — Distribution of top defense systems across domains

## Script

### `script_bubbleplot.R`

Generates the bubble plot shown in **Figure 2**, summarising the abundance and
distribution of defence systems across taxa.


## Input tables

### `ar53_padloc-sumtax.txt`
Summary of PADLOC-predicted defence systems for **Archaea** (ar53 dataset), aggregated by taxonomic level.

### `b120_padloc-sumtax.txt`
Summary of PADLOC-predicted defence systems for **Bacteria** (bac120 dataset), aggregated by taxonomic level.
